# Legionella Isolation Using Preincubation

## Overview

This repository contains the R code and input data used for statistical analyses and figure generation associated with a study investigating the effect of pre-incubation on the culturability of *Legionella* spp. in samples collected from industrial wastewater treatment plants (WWTPs).

The study compares culture results obtained from fresh samples and samples pre-incubated at 37 °C or at lower temperatures (27–34 °C). It also evaluates the effects of culture pre-treatments and activated sludge pre-filtration.

## Repository structure

```text
Legionella-Isolation-Using-Preincubation/
├── data/                            # Input CSV files
├── Pre-incubation_analysis_v1.0.R   # R analysis script
├── README.md                        # Repository documentation

```

The `output/` directory is created automatically when the script is executed.

## Requirements

The analyses were implemented in R using the following packages:

- ggplot2
- dplyr
- tidyr
- DescTools

Install the required packages using:

```r
install.packages(c("ggplot2", "dplyr", "tidyr", "DescTools"))
```

## Input data

The `data/` directory contains four CSV files:

| File | Description |
|---|---|
| `Concentrations_Pre-Inc_time.csv` | Culture results for fresh and pre-incubated samples |
| `Cult_pre-treatment.csv` | Culture results for different pre-treatments and filtration conditions |
| `T_profiles_LT_37.csv` | Temperature measurements during lower-temperature pre-incubation |
| `Legionella_27_37.csv` | *Legionella* species identification and corresponding pre-incubation temperatures |

## Statistical analyses

The R script performs the following analyses:

**McNemar's test**

- Comparison of culturability between fresh samples and samples pre-incubated at 37 °C.
- Comparison of culturability between fresh samples and samples pre-incubated at lower temperatures.
- Comparison of filtered and unfiltered activated sludge samples.

**Cochran's Q test**

- Comparison of culture-positive outcomes among four pre-treatments: untreated (U), acid (A), heat (T), and combined heat and acid (T+A).
- Additional comparison including filtered and unfiltered pre-treatments for activated sludge samples.

## How to reproduce the analyses

1. Download or clone this repository.
2. Install the required R packages.
3. Open R or RStudio and set the working directory to the repository root.
4. Execute:

```r
source("Pre-incubation_analysis_v1.0.R")
```

Alternatively, run the script from a terminal:

```bash
Rscript Pre-incubation_analysis_v1.0.R
```

The script automatically reads the input CSV files from `data/` and creates an `output/` directory containing:

- Eight figures in JPG format (350 dpi).
- `McNemar_preincubation.txt`
- `McNemar_filtration.txt`
- `Cochran_Q_pretreatments.txt`

**Note:** Existing files directly inside the `output/` directory are deleted when the script starts.
